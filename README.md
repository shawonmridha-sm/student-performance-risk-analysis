# SEC C Student Performance Dashboard
Open the folder containing app.py in VS Code. Python 3.11/3.12 recommended. Run python -m pip install -r requirements.txt then python -m streamlit run app.py. Alternatively use INSTALL.bat then START.bat.
Original notebook and saved model are included; no retraining. Original graphs are extracted from executed notebook. Upload data/new_student_dataset.csv for synthetic testing. Missing/invalid inputs are rejected; duplicate rows removed. Training used median imputation and IQR clipping; inference follows original single-student code and does not refit preprocessing. Original raw training CSV and neighbor ID mapping are unavailable; neighbor positions are not IDs. The original notebook preprocessing before splitting may inflate evaluation. Predictions are estimates for supportive review, not automatic academic decisions.
